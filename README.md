# Deep Field Cruiser

A cockpit view of the universe in your browser. Set the ship's speed from a slow drift to 1000× light speed and watch stars, nebulae and planets fly past.

**Play:** https://rizwanalikhan007.github.io/deep-field-cruiser/

## Controls
- Throttle slider, or ↑ ↓ / W S, or mouse wheel
- Space: full stop
- T: change theme (Deep Space, Neon Grid, Monochrome, Cartoon)
- H or double-click: hide the controls
- F: full screen
- Mouse or finger drag to steer; on phones, the tilt button steers by tilting

Share links keep the view: `?theme=neon&speed=60`

## Hosting
Plain static files, no build step. Works on GitHub Pages, Vercel, Netlify or any static host.
